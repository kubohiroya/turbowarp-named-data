Named Data

A shared named-data reference and provider registry for unsandboxed TurboWarp extensions.

Enable the MVP

globalThis.__TW_NAMED_DATA_FEATURE_FLAGS__ = {NAMED_DATA_REGISTRY_MVP: true};

Set the startup-fixed flag before loading dist/named-data.js. It is disabled by default.

Contract

Providers resolve structured, document, binary, and asset references into metadata and a releasable byte or stream body. Payload is never embedded in a reference or manifest.

See the repository README and architecture documents for provider and lifecycle details.
